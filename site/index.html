Questions

Is it free?

Yes, for personal and other noncommercial use. Selling it or using it in a paid product or service needs the author's permission.

Does Audora send any data?

No. There is no account, no tracking and no telemetry. Audora does not use the internet, and your audio is never saved or sent anywhere.

Does this website track me?

No cookies and no analytics. The page only asks GitHub which version is the newest and how big the downloads are. The download buttons work without that.

Will it change my Windows sound?

Audora starts off, and while it is off it does nothing to your audio. When it is on, it changes the Windows volume, mute or default device only when you ask. Restore Windows audio puts them back.

How many Bluetooth devices can play at once?

That depends on your PC's Bluetooth adapter, usually two to four. Audora has no limit of its own.

Why is one device a little behind the others?

Windows plays the default device directly, and Audora copies the sound to the rest. Bluetooth is usually the most behind. Each device has its own delay setting to line them up.

Why can't I change the sound of my default device?

Windows plays that device directly. Turn on Full control in Settings, with a free virtual audio cable, and every device can be changed.

Why does Windows warn me about the installer?

The installer is not code-signed yet, so Windows SmartScreen may say "unknown publisher". Choose More info, then Run anyway. You can check the file with the SHA-256 line in the Download section.

Which versions of Windows work?

Windows 10 (1809 or newer) and Windows 11, 64-bit. There is nothing else to install.

How do I uninstall it?

Windows Settings, Apps, Audora, Uninstall. For the portable version, delete the folder.
