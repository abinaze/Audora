# Security Policy

## Supported versions

Only the latest release gets security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for a security problem.

Use GitHub's private reporting instead: go to the **Security** tab of this repository and
choose **Report a vulnerability**. Include what you found, how to reproduce it and which
version you used.

We aim to reply within a week and to fix confirmed problems as quickly as we can. We will
credit you in the release notes if you would like that.

## What Audora does on your computer

- It listens to your default audio output, in memory only, so it can play the same sound
  on other devices. It never saves audio to disk and never sends it anywhere.
- It does not connect to the internet and has no accounts or telemetry.
- It may change your Windows default audio output when you ask it to.
