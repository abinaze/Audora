# Getting help

1. Read [Troubleshooting](docs/TROUBLESHOOTING.md). It covers the most common problems.
2. Ask a question in [Discussions](https://github.com/abinaze/Audora/discussions).
3. Found a bug? [Open an issue](https://github.com/abinaze/Audora/issues/new/choose) and
   include your devices and Windows version. The template will guide you.

For security problems, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
